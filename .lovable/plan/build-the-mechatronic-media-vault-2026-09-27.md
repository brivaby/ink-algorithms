# Build the Mechatronic Media Vault

## Scope
- Replace the blank home screen with the supplied technical media archive.
- Recreate the reference’s industrial documentation style, dense hierarchy, and responsive layout.
- Use the referenced Google-hosted photography directly, as requested.

## Experience
- Add the archive header, category filters, featured recording cards, live telemetry strip, component photo vault, capture protocol, and audit matrix.
- Make filters update visible media and counts.
- Make video and photo cards open an inspection overlay with the relevant image and technical details.
- Add close, playback, progress, speed, and volume controls to the recording overlay.

## Technical details
- Build the page as the `/` route using React and the existing Tailwind setup.
- Define all colors, typography, borders, and motion as semantic design tokens in the global design system.
- Add complete page metadata and preserve keyboard accessibility and reduced-motion preferences.
- Verify the finished page at desktop and mobile sizes, including overlays and filtering.
